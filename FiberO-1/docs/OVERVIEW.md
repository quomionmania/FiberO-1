# FiberO-1 Overview

FiberO-1 is a **standalone** multi-class agent/system, separate from the Fiberglass family DNA.

## Classes

| Class | Purpose | Posture | Recommended model profile |
|---|---|---|---|
| 3d | 3D assets/scenes/render pipelines | Maximum design/detail, token/credit intensive when requested | Spatial/visual reasoning + 3D tools |
| coding | Software engineering | Correct, test-aware, maintainable | Best coding/reasoning model |
| design | UI/UX/visual systems | High craft, no generic slop | Visual/design reasoning model |
| music | Composition/sound design | Creative + structured | Creative model + audio tools |
| motion | Animation/motion graphics | Frame/beat-aware | Timing-aware model + motion tools |
| video | Video pipelines/editing | End-to-end | Multimodal/video model + ffmpeg |
| research | Docs/web synthesis | Evidence-first | Fast broad model + browsing |
| general | Mixed tasks | Practical | Balanced general model |

## PC Control Mode

The Windows prototype in `../pc-control/` demonstrates:
- visible overlay: "FiberO using the PC"
- global Esc kill switch
- safe demo mouse movement

It is experimental. Use with caution and keep Esc accessible.
