# Fiberglass 5.0 Package

This folder packages **Fiberglass 5.0** prompts in three formats:

- `opencode/agents/` - OpenCode agent markdown files (original frontmatter preserved)
- `claude/` - Claude system/project prompt files (original prompt preserved)
- `chatgpt/` - ChatGPT custom instruction/prompt files (original prompt preserved)

Included agents:

- **Nature** (`fiberglass-5.0-nature`) - cost-benefit profile
- **Atmosphere** (`fiberglass-5.0-atmosphere`) - high-volume coverage profile

The original 5.0 prompts are preserved for fidelity. Package documentation is in English.
