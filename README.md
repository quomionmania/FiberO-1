FiberO-1 is a standalone, open-source multi-class agent system. It routes work by class (3D, coding, design, music, motion, video, research, general), recommends model profiles per class, and ships prompt packs for OpenCode, Claude, and ChatGPT.

This release also includes:
- A Windows PC-control prototype with a visible "FiberO using the PC" overlay and an Esc emergency kill switch.
- Fiberglass 5.0 (Nature + Atmosphere) prompt packs for OpenCode, Claude, and ChatGPT.

Status: experimental/prototype. Verify in your environment before production use.
